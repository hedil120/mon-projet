🌐 Dashboard API – Projet de Stage

Ce projet est un tableau de bord web interactif qui affiche des données en temps réel à partir de plusieurs API publiques : météo, cryptomonnaies et statistiques GitHub.


#Objectifs du projet

- Intégrer plusieurs API REST publiques.
- Afficher les données de manière claire avec du JavaScript.
- Utiliser des graphiques pour visualiser l’évolution des données.
- Concevoir une interface responsive et agréable.


#Fonctionnalités

- Recherche de profil GitHub + dépôts récents.
- Affichage aléatoire des cours de cryptomonnaies.
- Météo actuelle + prévision 5 jours selon la ville ou géolocalisation.
- Thème sombre/claire.
- Graphiques dynamiques avec Chart.js.


#APIs utilisées

|     API      |   Description                     |                              Authentification                             |
|--------------|-----------------------------------|---------------------------------------------------------------------------|
| GitHub API   |(https://docs.github.com/en/rest)  | Récupère les données d’un utilisateur GitHub  |     Pas besoin de clé     |
|CoinGecko API |(https://www.coingecko.com/en/api) | Cours et infos sur les cryptos.               |     Pas besoin de clé     |
|OpenWeatherMap|(https://openweathermap.org/api)   | Météo actuelle et prévisions.                 |     Clé API requise       |
